# 设计规范 - AI智能求职匹配平台

## 颜色主题

| 用途 | 颜色值 | Tailwind类名 |
|---|---|---|
| 页面背景 | `#F5F9FF` | `bg-[#F5F9FF]` |
| 主按钮/强调 | `#42A5F5` | `bg-[#42A5F5]` |
| 卡片背景 | `#BBDEFB` | `bg-[#BBDEFB]` |
| 深蓝文字/标题 | `#1E88E5` | `text-[#1E88E5]` |
| 浅蓝导航栏 | `#E3F2FD` | `bg-[#E3F2FD]` |
| 悬停状态 | `#1976D2` | `hover:bg-[#1976D2]` |
| 成功/高分 | `#4CAF50` | 绿色（匹配度≥70%） |
| 文字色 | `#333333` | 深灰 |

## 组件规范

### 导航栏
- 高度: 56px
- 背景: `#E3F2FD`
- 左侧: 应用名称 "AI智能求职助手"
- 右侧: 城市选择器下拉菜单

### 简历上传区
- 虚线边框 2px dashed `#42A5F5`
- 圆角 8px
- 拖拽悬停时变色加深
- 支持点击上传

### AI对话组件
- 气泡样式：用户右侧蓝色、AI左侧白色
- 最大高度限制，超出滚动
- 输入框固定在底部
- 发送按钮右下角

### 岗位卡片
- 白色背景，圆角 12px，轻微阴影
- 标题 + 公司名 + 城市
- 匹配度进度条（绿色≥70%，灰色<70%）
- 来源标签
- "更新简历"按钮右侧

### 城市选择器
- 下拉菜单，支持搜索
- 多选模式（最多3个）
- 选中标签展示在导航栏

## 响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| 手机 | < 768px | 单列堆叠 |
| 平板 | 768-1024px | 双列 |
| 电脑 | > 1024px | 左右分栏 |

## 字体
- 系统默认字体: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`
