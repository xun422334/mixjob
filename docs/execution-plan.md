# 执行步骤 - AI智能求职匹配平台

## 执行原则
- 每阶段完成并验证后，再进入下一阶段
- 每阶段先做后端API，再做前端组件
- 每天开发结束后更新 devlog/

---

## 阶段0：项目基础设施
1. 创建 docs/ 文件夹 + 4份文档
2. 创建 devlog/ 文件夹
3. 创建 CLAUDE.md
4. 初始化前端项目（React + Vite + TypeScript + Tailwind）
5. 初始化后端项目（FastAPI + SQLite）
6. 配置浅蓝色主题
7. **验证**：前后端各自启动成功

## 阶段1：简历上传与解析
1. 后端：文件上传API
2. 后端：PDF/Word文本提取
3. 后端：DeepSeek结构化提取
4. 后端：数据模型 + 存储
5. 前端：拖拽上传组件
6. **验证**：上传PDF简历 → 看到结构化结果

## 阶段2：AI对话 + 城市选择
1. 后端：聊天API
2. 后端：城市列表API
3. 后端：对话中提取城市
4. 前端：ChatDialog组件
5. 前端：CitySwitcher组件
6. **验证**：对话 + 城市切换

## 阶段3：岗位数据层 + 手动导入
1. 后端：JobListing模型 + CRUD API
2. 前端：手动导入表单
3. **验证**：手动添加 + 列表展示

## 阶段4：匹配推荐引擎
1. 后端：关键词提取 + AI评分
2. 后端：推荐API
3. 前端：JobCard组件
4. **验证**：推荐列表带匹配度

## 阶段5：岗位抓取引擎
1. 后端：抓取器实现
2. 前端：一键抓取按钮
3. **验证**：抓取 → 入库 → 推荐

## 阶段6：更新简历功能
1. 后端：AI生成优化简历 + docx下载
2. 前端：更新简历按钮
3. **验证**：下载docx可打开

## 阶段7：整体打磨
1. 响应式适配
2. 错误/空状态处理
3. 完整流程走通
